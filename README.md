# Scenic Clipper

A Windows app that turns long recordings into the best short vertical clips for TikTok,
YouTube Shorts and Instagram Reels, with a montage cut to music. Made for game build
showcases, and it also handles gameplay highlights, talking videos and any other footage.
Everything runs on your PC; nothing is uploaded.

This page only hosts the downloads. The app checks it for updates by itself.

## Install

1. Download the zip from the [latest release](../../releases/latest).
2. Right-click it, choose **Extract All**, and open `ScenicClipper.exe` from the extracted folder.
3. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**
   (the app isn't code-signed).
4. In the app, press **Add-ons… > Install all** once for the smart features.

`HOW TO USE.txt` in the folder explains everything.

## Updates

When a new version is out, the app downloads it quietly and shows **Restart to update**.
Settings and add-ons are kept.
